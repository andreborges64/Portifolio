# André Borges — Portfólio

Portfólio pessoal responsivo de André Luiz Silva Dias Borges. O visual combina esporte, tecnologia e criatividade para apresentar projetos web e experiências interativas.

## O que tem no site

- Layout mobile first com tema escuro e detalhes esportivos.
- Cards filtráveis para 15 projetos; cada card abre o site publicado no GitHub Pages em uma nova aba.
- Capturas de tela geradas sob demanda pelo [thum.io](https://www.thum.io/).
- Fundo com raios de luz que se movem suavemente durante a rolagem.
- Links de contato para GitHub, LinkedIn, Instagram e WhatsApp.
- Animações respeitam a preferência do sistema por movimento reduzido.

## Publicar no GitHub Pages

1. Abra **Settings → Pages** neste repositório.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch `main` e a pasta `/(root)`, então salve.
4. Após a publicação, o endereço será `https://andreborges64.github.io/Portifolio/`.

As imagens de capa dependem de uma conexão com a internet para carregar do thum.io e das páginas públicas de cada projeto.

## Desenvolvimento local

Abra `index.html` em um navegador ou sirva esta pasta com qualquer servidor estático. O site usa HTML, CSS e JavaScript sem etapa de build.
